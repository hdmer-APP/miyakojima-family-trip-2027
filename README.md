# 宮古島家庭旅行 2027

2027/5/13–5/17（母親節後一週）宮古島五天四夜家庭旅行的公開單頁網站。

公開網址：https://hdmer-app.github.io/miyakojima-family-trip-2027/

- 公開首頁：根目錄 `index.html`
- 內容來源：`docs/docsite.config.json`、`docs/site/*.html`
- 重新產生：先執行 doc-site 生成器，再執行 `node docs/build-standalone.cjs`
- 星宇官網目前尚無 2027 年 5 月適用票價；5/13（四）去、5/17（一）回符合現行台北直飛基準班次，仍須待 2027 班表與票價開放。
- 2026-08-12 查詢時，White Shisa 5/13–5/17 四晚可訂；原 2＋2 住宿候選在新日期多數不可訂。

網站只放行程與公開訂房／餐廳連結，不放旅客姓名、訂位編號或聯絡資料。
